# SkillPath Domain Model

This context defines the core language for the educational paths and assessment system in SkillPath.

## Language

**Roadmap**:
A predefined educational path containing a structured sequence of learning nodes. Students can be enrolled in multiple roadmaps simultaneously.
_Avoid_: Track, course, path

**Node (Roadmap Node)**:
A specific requirement within a roadmap, defined by a Category, Level (e.g., JUNIOR), and a target Difficulty (e.g., EASY).
_Avoid_: Step, card, milestone

**Level (Roadmap Level)**:
A conceptual tier within a roadmap (JUNIOR, MIDDLE, SENIOR). A student advances to the next level in a roadmap only when all nodes in their current level are passed.
_Avoid_: Stage, phase

**Category**:
A universal knowledge domain (e.g., OOP, Databases). Categories are agnostic of career level or difficulty.
_Avoid_: Topic, subject

**Difficulty**:
The intrinsic complexity of a Question (EASY, MEDIUM, HARD) and the target complexity required by a Node.
_Avoid_: Level (to avoid confusion with Career/Roadmap Level)

**Assessment**:
A test session taken by a student. Assessments can be generated in two ways:
1. **Single-Category**: Tests exactly one Category at one Difficulty (e.g., an "OOP - EASY" test).
2. **Mixed-Category (Surprise Mode)**: Tests multiple nodes simultaneously. It is generated by taking the required nodes from a student's current level. If the level requires multiple difficulties for the same category (e.g., OOP-EASY and OOP-MIDDLE), the Surprise Mode test will logically include only the highest difficulty (OOP-MIDDLE) to avoid redundancy and leverage Difficulty Cascading.
Even in mixed tests, scores are recorded individually per category and difficulty.
_Avoid_: Quiz, exam

**Universal Score**:
The principle that an assessment result is tied to the student, category, and difficulty, not to a specific roadmap. Passing a category at a specific difficulty automatically passes the corresponding nodes in all active roadmaps the student is enrolled in.

**Difficulty Cascading**:
The rule that achieving a passing score (>= 90%) at a higher difficulty (e.g., HARD) automatically validates any roadmap nodes for the same category at lower difficulties (MEDIUM, EASY).
